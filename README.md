# 🛒 বাজার দর (BazarDor)

📌 BazarDor is a web application that helps users explore and compare the latest prices of everyday grocery products in Bangladesh. Users can browse products by category, check current prices, and view price changes through a simple and user-friendly interface.

### 🛠️ Technologies Used

-  Next.js
-  React
-  TypeScript
-  Tailwind CSS
-  HeroUI
-  Better Auth
-  REST API
-  React Hot Toast
-  Gravity UI Icon


### ✨ Key Features

1. View grocery product prices.
2. Browse products by category.
3. Sort products by price.
4. User sign up and sign in.
5. Responsive design for mobile and desktop.
